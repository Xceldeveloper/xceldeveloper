# Overcomer Emiator

Personal site — a digital card for **Overcomer Emiator**: builder, solution architect, and founder of [Sleekware](https://sleekware.io).

## Stack

Nuxt 4 · Vue 3 · TypeScript · SCSS · GSAP

## Develop

```bash
npm install
npm run dev
```

Runs at [http://localhost:3050](http://localhost:3050).

- Splash / lockup: `public/theovercomer.png`
