# Overcomer Emiator

Personal site — a digital card for **Overcomer Emiator**: builder, solution architect, and founder of [Sleekware](https://sleekware.com).

## Stack

Nuxt 4 · Vue 3 · TypeScript · SCSS · GSAP

## Develop

```bash
npm install
npm run dev
```

Runs at [http://localhost:3050](http://localhost:3050).

## Brand assets

- Splash / lockup: `public/theovercomer.png`
- Favicon: `public/favicon.ico` (+ PNG sizes, apple-touch)
- SEO / Open Graph: `public/og-image.jpg` (1080×1080)
